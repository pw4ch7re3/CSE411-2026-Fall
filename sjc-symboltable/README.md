# Assignment 7: Symbol Table Construction

## Task

Your task is to build a symbol table for Static Java programs.

1. Complete the implementation of [src/main/java/sjc/symboltable/SymbolTableBuilder.java](src/main/java/sjc/symboltable/SymbolTableBuilder.java).
2. Ensure that your implementation passes all the provided JUnit test cases in [src/test/java/sjc/test/SymbolTableBuilderTest.java](src/test/java/sjc/test/SymbolTableBuilderTest.java).

### Testing

Run the symbol-table tests from the repository root:

```sh
sbt sjcSymbolTable/test
```
