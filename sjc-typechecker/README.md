# Assignment 8: Type Checking

## Task

Your task is to build a type checker for Static Java programs.

1. Complete the implementation of [src/main/java/sjc/type/checker/TypeChecker.java](src/main/java/sjc/type/checker/TypeChecker.java).
2. Ensure that your implementation passes all the provided JUnit test cases in [src/test/java/sjc/test/TypeCheckingTest.java](src/test/java/sjc/test/TypeCheckingTest.java).

### Testing

Run the type-checker tests from the repository root:

```sh
sbt sjcTypeChecker/test
```
